# 变异测试基线（dm-git）

脚本：`scripts/mutation_test_dmgit.py`

做法：复制源码 → 逐个改坏关键判断 → `go build` → 在 18089 起独立实例 →
跑一组基线全绿的 HTTP 检查；任一检查失败即“杀死”该变异体。

覆盖：admin API 鉴权、项目读权限、git 私有仓库、项目页面、命名空间所有者、
禁用用户会话、名称校验、CSRF 副作用、npm 发布鉴权、备份 API、项目删除。

## 结果

```text
13/13 = 100%
```

说明：

- 鉴权、路径、输入校验、CSRF、会话失效这些有明确断言的检查，杀伤力是 100%；
- 第一轮唯一的幸存者是把「删除项目」的管理员校验删掉；补了 `delete-authz`
  （owner 把 attacker 加为 guest，guest 尝试删除）后，该变异体被杀死；
随后补了成员管理、项目设置两个鉴权变异体，同样被杀死。
- 变异测试只衡量**这组检查**，不等于 371 条平台用例的整体杀伤率；但它能定位
  “哪一类断言其实没有牙齿”。

下一步：为破坏性操作增加“一次性资源 + 权限拒绝 + 清理”的用例，再重跑基线。
